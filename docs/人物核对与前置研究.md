# 人物核对与前置研究

## 先承认已经发生的错误

第三集“太子为何主动交出户部”的成片把八阿哥的行为归给太子。用户已明确纠正。旧版的语义审片、时长检查和视频解码通过，不能证明人物归属正确。按本轮要求，旧影片、封面和发布记录全部保留，不进行重做或替换。

本地第三集的证据顺序：

| 原片时间 | 证据与核对意义 |
|---|---|
| 16:38–17:12 | 前一场对话出现“太子爷”；不能把这个称呼带进下一场 |
| 17:16.92–17:47左右 | 一名皇子自陈管理户部的问题、推荐四阿哥、呈上辞呈；“儿臣”本身不是身份标签 |
| 18:06.98–18:25左右 | 康熙另行点名太子，随后出现太子的回应 |
| 18:41.64–18:49.58 | 对白同时提及“太子和八弟”，两人不能合并 |
| 19:27.98–19:38左右 | 大臣建议八阿哥继续管理户部，与四阿哥共同办理 |

时间对应本项目当前原片版本。上述证据链、用户纠错以及[央视第三集简介](https://dianshiju.cctv.com/2010/09/02/VIDE1355623927578141.shtml)相互参照。旧稿为何犯错不能从模型内部得到证明；“跨场景沿用太子身份”是结合输入上下文推断出的可能诱因。

## 方法分成四层

1. **剧集背景与人物表。** 记录标准姓名、别称、关系、身份随时间的变化和来源。先解决太子、四爷、八爷、十三爷是谁，以及哪些称呼不能唯一识别人。背景资料不能直接确认画面里是谁。
2. **本集事件账本。** 按当前原片整理事件、暂定参与者、起止时间、字幕编号、身份依据、疑点。把“谁提出”“谁执行”“谁受益”“谁被提及”分开。事件描述和动机推断分开保存。
3. **场景身份核对。** 对写进标题和观点的关键主语，回看连续原声、点名后的回应和角色画面。抽样画面可能是听话人的反应镜头，不能单凭同期字幕认说话人。需要逐步建立经核对的角色画面锚点和场景连续性记录。
4. **解说主张审核。** 每个重要结论回到具体事件与身份依据。背景、原片与推断冲突就留疑点；不能用“这位皇子”等泛称掩盖实际归错了行为的问题。动机分析用“可以理解为”等措辞，并考虑其他解释。

这轮实现了前两层的自动初稿与生产接入，并强化各轮审片中的身份核对要求。第三层尚未完成自动人物画面匹配，第四层仍由模型审查，**不能承诺已根治人物错认**。以上为前置研究阶段的记录。后续已接入本地人物参考和关键行为归属拦截，当前结果与使用方法见[人物归属独立检查](人物归属独立检查.md)；真实画面错配仍未解决。

## 已实现的独立流程

在仓库根目录执行：

```bash
# 一集或整个素材目录：只生成资料，不制作或修改影片
.venv/bin/python -m autoclip research "videos/雍正王朝" \
  --config configs.production.toml --output output/剧情资料
```

每集输出：

- `剧情资料.md`：按时间排列的详细事件初稿，附原始ASR索引。
- `research.json`：结构化事件、暂定参与者、推断、其他解释、疑点。
- `research-usage.json`：本次调用数量和缓存统计。
- `source.json`、`transcript.json`：原片版本与字幕证据。

人物背景在`autoclip/knowledge/yongzheng.json`维护，附来源和限制。当前是核心人物表，不是完整人物百科；其他作品不会套用此表，也不会自动上网生成百科。新作品应先补有来源的人物表。

缓存绑定原片身份、字幕内容、人物表、模型、服务地址和流程版本。重复运行可复用；素材或资料改变会重新整理。事件引用必须是该区间真实存在的字幕编号；时间及引用文本由程序从原字幕提取，不由模型虚构。模型无权把自身输出标成“已核实”。这些是数据完整性检查，并非语义正确性证明。

`configs.production.toml`已开启`research_before_produce = true`。正常`produce`先整理资料，再理解和选题；相关研究初稿交给编导作线索，编导仍须返回原片核对。跨批次可以复用同一原片的有效研究缓存。每集通常增加约9次首次模型请求，原有API次数上限仍生效。资料不足或生成失败时明确报错，不静默跳过。

## 资料覆盖与限制

本轮使用用户提供的01–06集整理详细初稿，未获得的后续原片不补写成“已观看”的逐集详解。官网简介只辅助背景核查，不能代替本地版本的时间码。ASR中姓名、金额和官职仍可能错误；初稿会保留这些风险，不能直接当成发布稿。

对用户提供的解读样片，研究结果见[解读样片评估](解读样片评估.md)。该视频用于分析表达方法，不作为本剧事件的权威资料，也不把它的全文放进仓库或写稿提示中。
