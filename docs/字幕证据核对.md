# 原片字幕证据核对与可撤销纠错层（v1.1）

本命令从原片中提取字幕区域，调用配置中的Flash模型逐帧抄录，并生成可追溯的纠错建议。核对工具不修改原始ASR或成片；v1.1支持额外导出纠错层，通过`produce --subtitle-layer`明确启用。默认生产行为不变。

在项目目录执行，素材路径和字幕ID按自己的文件替换：

```bash
.venv/bin/python -m autoclip.evidence \
  '/path/to/episode.mp4' \
  'output/episode-id/transcript.json' \
  --ids 285,654,672,685 \
  --neighbors \
  --config configs.production.toml \
  --output output/字幕证据
```

从项目外执行时，将Python、素材、字幕、配置及输出目录写为绝对路径。读取配置文件旁的`.env`；运行不依赖Codex。字幕截图会发送到所配置的模型接口并产生调用费用。`--neighbors`增加间隔不超过1.5秒的直接前后句，不递归扩展整场对白。每条通常2次请求；一帧无字幕时最多补1帧，字幕发生切换时最多补2帧，每条最多4帧。网络重试受`max_api_calls`限制，结果缓存于独立输出目录；同样输入再次执行复用缓存。

报告保存在输出目录的`<任务指纹>/evidence.json`，截图在同目录`frames/`。指纹包含素材标识、字幕文件哈希、所选ID、模型、接口及工具版本。每条报告保留原字幕、时间、置信度、截图及其哈希、两次读数、建议与判定原因。

| 状态 | 含义 |
|---|---|
| `confirmed` | 两帧抄录与ASR一致，比较时忽略标点、空白和全角差异 |
| `proposed_correction` | 两帧抄录一致，与ASR存在有限差异，形成待验证建议 |
| `unresolved` | 不可读、不一致、过短或差异过大，暂缓处理 |

模型调用失败会使命令失败、报告状态记为`failed`，不会记成字幕错误。报告中的`usage`记录模型请求及token用量；实际计费以服务商账单为准。

当前在每条ASR区间的35%和65%位置截取画面底部32%，缩放到960像素宽。字幕位置不同、上下双行、字幕切换与ASR边界错位可能使结果无法判定。两帧抄录来自同一模型，可能同时读错；字符相似度仅是保守拦截条件，不能判断语义正确或人物身份。可见字幕本身也可能有错。因此核对命令本身不替换文字，也不把该结果当作说话人或剧情事实核验结论。

报告的`alignment`保留三种关系：一对一、最多3条相邻ASR对应一句画面字幕、一条ASR对应连续两句画面字幕。每句可见字幕至少要有两个一致读数；可读但互相冲突的读数不能通过多数投票忽略。重复字幕有多种同样可信的组合时暂缓。字幕切换记录为两个观察时间之间的范围，不输出猜测的逐字时间。更复杂的多对多情况仍待实现。

## 导出与使用纠错层

核对完成后，用实际报告路径替换以下示例。输出文件必须尚不存在，防止覆盖已有证据或字幕：

```bash
.venv/bin/python -m autoclip.corrections \
  'output/字幕证据/<任务指纹>/evidence.json' \
  --output output/字幕证据/corrections.json

.venv/bin/python -m autoclip produce '/path/to/episode.mp4' \
  --config configs.production.toml \
  --subtitle-layer output/字幕证据/corrections.json \
  --output output/字幕纠错新批次
```

首次验证可增加`--stage scout`，只运行理解和选题。纠错层仅支持单个素材文件，不能用同一文件直接处理整个剧集目录。

只有两帧以上一致、原文至少7字、字数不变、最多替换2个汉字且原字保留比例不低于70%的条目，才会进入纠错层。变动涉及数字、金额常用数字字形时暂缓；短姓名、增删字、跨分段推断不进入。该门槛限制改动范围，并非正确率保证，后续编导和语义审核继续执行。

纠错层绑定素材指纹、完整原始字幕指纹、原句、时间及画面哈希。素材、字幕、纠错文件或证据改变时会停止并要求重新核对，不能套用旧文件。它只替换对应ID的文字，不改变ID、时间或原置信度；不做全局姓名替换。

生产目录的`transcript.json`保留原识别；`transcript.effective.json`是本次实际输入，`transcript-input.json`记录启用的纠错层和改动ID。有效文字进入模型请求、选题及编导缓存指纹，避免套用旧稿。撤销时移除`--subtitle-layer`即可恢复原始输入；已完成的影片仍被保留，不自动重做。

目前仍需通过核对命令指定待检查的字幕ID。尚未默认自动扫描所有台词，也未完成人物身份或说话人核验。真实样本、合成边界测试和下一步任务分别记录在[迭代计划](迭代计划.md)。
