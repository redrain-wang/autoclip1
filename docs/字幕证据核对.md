# 原片字幕证据核对（试验入口）

本命令从原片中提取字幕区域，调用配置中的Flash模型分别抄录两帧，并生成可追溯的纠错建议。它目前是独立的只读试验，不自动接入`produce`，不修改原始ASR、已完成成片或生产勘误词表。

在项目目录执行，素材路径和字幕ID按自己的文件替换：

```bash
.venv/bin/python -m autoclip.evidence \
  '/path/to/episode.mp4' \
  'output/episode-id/transcript.json' \
  --ids 285,654,672,685 \
  --config configs.production.toml \
  --output output/字幕证据
```

从项目外执行时，将Python、素材、字幕、配置及输出目录写为绝对路径。读取配置文件旁的`.env`；运行不依赖Codex。字幕截图会发送到所配置的模型接口并产生调用费用。每条通常2次请求，网络重试受`max_api_calls`限制，结果缓存于独立输出目录；同样输入再次执行复用缓存。

报告保存在输出目录的`<任务指纹>/evidence.json`，截图在同目录`frames/`。指纹包含素材标识、字幕文件哈希、所选ID、模型、接口及工具版本。每条报告保留原字幕、时间、置信度、截图及其哈希、两次读数、建议与判定原因。

| 状态 | 含义 |
|---|---|
| `confirmed` | 两帧抄录与ASR一致，比较时忽略标点、空白和全角差异 |
| `proposed_correction` | 两帧抄录一致，与ASR存在有限差异，形成待验证建议 |
| `unresolved` | 不可读、不一致、过短或差异过大，暂缓处理 |

模型调用失败会使命令失败、报告状态记为`failed`，不会记成字幕错误。报告中的`usage`记录模型请求及token用量；实际计费以服务商账单为准。

当前在每条ASR区间的35%和65%位置截取画面底部32%，缩放到960像素宽。字幕位置不同、上下双行、字幕切换与ASR边界错位可能使结果无法判定。两帧抄录来自同一模型，可能同时读错；字符相似度仅是保守拦截条件，不能判断语义正确或人物身份。可见字幕本身也可能有错。因此当前不自动替换文字，不把该结果当作说话人或剧情事实核验结论。

生产接入前，先扩展固定验收样本并处理字幕与ASR的多对多时间对齐，具体进度持续记录在[迭代计划](迭代计划.md)。
