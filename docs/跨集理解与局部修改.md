# 跨集理解与局部修改

## 整集分析与前情

常规生产先读取全集字幕，每300秒分析一个区间，所有区间完成后才进入集中选题。早段出现候选不会中止扫描。没有对白的区间也记入覆盖记录，但不会仅凭空白字幕编造故事。画面仍为抽样，不能把此流程称为逐秒观看整集。长片目前使用开发核定的章节提纲，尚未完成自动提纲的实片验证。

运行目录新增 `analysis-coverage.json`，显示原片总长、分段范围、各段字幕数与候选数。中途失败不会把旧的完成状态当作本次扫描成功。这是进度记录，不增加候选条数或新的出片门槛。

前情默认寻找同一素材目录、同一剧名的最近三集已有资料，数值可用 `previous_episodes` 调整，0关闭。支持当前的 `01.mp4`、`第01集.mp4` 和 `S01E01.mp4` 命名；不能识别集数时仍可处理本片，不猜顺序。资料默认从配置文件旁的 `output/` 获取，可用 `continuity_history` 指定其他目录；相对路径按配置文件目录解析。

- 本地 `continuity.json` 保存前集完整ASR、时间码、研究事件与资料来源。
- 给模型的前情按当前场景提取相关事件及其台词，同时保留分布在前集中不同位置的事件，避免只取开头；不会每次重跑前集模型。
- 交付稿优先使用有对应开发核对备注的版本，再选最新成功交付；没有核对备注时使用最新交付稿。未通过的草稿和暂扣成片不进入前情。旧稿中的分析仍标为解说分析，不升格为剧情事实。
- 本集和后集不当作前情。前集台词编号与本集编号分开，素材版本变化后不沿用旧资料。
- 缺少前情时继续本集生产，不要求补齐一季才开工。

顺序为：**本集字幕/抽样画面 → 本集事件与候选 → 加入前情集中选题 → 带前情写稿 → 现有内容与身份检查**。分集研究同时保存前情，但事件提取只看本集；长稿 `write-outline` 分章写作读取相同的前情。

这样安排来自真实反例：第六集首次测试把大量前情直接放入分段分析，模型把第三集接风宴混入第六集背书场景。改为先整理当前事件，再在选题/写稿阶段接入前情；原失败结果保留在本地验收目录。分层减少混淆来源，不代表人物、剧情判断已经自动准确。

只检查前情，不调用模型：

```bash
.venv/bin/python -m autoclip episode-context "videos/雍正王朝/06.mp4" \
  --config configs.long-yunjian.toml --output output/前情检查
```

输出 `continuity.json` 和便于阅读的 `前情输入.txt`。本地剧情资料、稿件、原片、模型响应均保持在忽略目录。

## 改一句解说

按实际成片时间定位，要提供该片的定稿计划和渲染清单；清单包含输出时间与原片时间的对应关系。`03:15` 是成片时间，不是原片时间。程序生成新稿和差异记录，原计划与成片不变。

```bash
.venv/bin/python -m autoclip edit-narration \
  --plan output/我的长片/plan-timed.json \
  --manifest output/我的长片/对应渲染目录/manifest.json \
  --at 03:15 --text "承诺已经说出口，银子却还没有到账。" \
  --output output/我的修订/plan.json
```

也可用 `--beat 12` 替代 `--at` 和 `--manifest`，段号从0开始。时间落在原声上时会提示定位到解说段，不会替换原声台词。新稿继续使用原有测时和内容核对流程；原来的核对记录不自动批准新文字。没有增加新的人工审批步骤。

## 哪些能复用

生产配置自动将语音和未烧录字幕的片段保存到 `output/.media-cache/`，可用 `media_cache` 改位置。文件内容相同的片段跨稿件、跨运行目录复用，缓存命中不跳过原有内容检查。

- 改一句话：仅新文字需要配音，实际改变的片段重新编码，其他片段复用。
- 换配音声音或语速：解说音频重新合成，原声片段可复用。
- 改标题、字幕、封面或水印：无须重做剧情分析或未受影响的片段。封面/水印仍使用已有品牌包装入口。
- 原片、画幅、画面时间、配音音频或混音音量变化：相关片段重新生成，不误用旧缓存。
- 片段写入中断或文件损坏：不当作完整缓存；相同片段并发请求只生成一次。

字幕位置会随前段时长变化，因此最后的拼接、字幕烧录和包装仍需执行，不能理解为修改一句后整片零耗时。旧版片段缓存不会批量转换；新生成的片段开始使用共享缓存。原有配音在运行目录中命中时会自动复用。

本次用真实FFmpeg四段测试片验证：初次编码4段，改一段配音后仅编码1段、复用3段，新旧影片均保留。单元测试同时覆盖换声、换原片、换画幅、损坏缓存、按成片时间修改及旧稿保护。
