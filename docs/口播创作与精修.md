# 口播创作与精修

2026-10-12用户认可加长试片，同时明确要求以后减少审稿式语言。早期核定片保留；这些规则用于后续新稿与明确要求的重制。

## 首稿的问题来自哪里

此前写稿提示要求动机分析允许另一种解释，比稿又强制正文展示其他解释和证据局限。事实纠错之后，缺少专门面向听众的精修，导致模型把“客观定论、控诉方的推论、单凭问答不能断定”等审核措辞带进口播。限定有时必要，但重复排除、额外猜心与同义总结会削弱观点，也会造成一种错觉：似乎没有审查术语，就没有严谨的分析。

## 新稿规则

- 可见行动直接讲；角色指责用“在田大人的解释里”“他说……”自然交代来源，一次归属覆盖该段分析。
- 来源清楚以后讲机制、选择、压力和代价，不再重复提醒“这不是认罪、未必、证据只到……”；不要求额外补一种心理猜测。
- 关键未知保留，例如谁实际出钱、钱最终去了哪里、是否到账；它们影响结论，不能为了顺口写成已发生事实。
- 对不推进主题的心理猜测直接舍弃，优先分析已出现的行动和角色明确说出的理由。
- 关键交锋才展开有具体依据的判断，普通转场不硬加观点；章节递进，结尾回应主问题，避免反复换词解释同一结论。原声已经讲清的动作不再长篇复述。
- 检查真实听感，不能把“客观定论”换成“人格结论”、把“不能断定”换成“没把用意说透”就算完成。

## 程序流程

普通新片：创稿与时间线 → 口播精修及增量核对 → 完整内容/画面审查 → 人物归属检查 → 实际配音测时及必要修稿 → 渲染前检查实际口播。

长篇提纲：分章写稿 → 全稿口播精修及增量核对 → 保存尚未审片的计划 → 配音测时 → 逐段开发核对 → 固定稿渲染。这是既有 `render-sample` 开发核对路径。新增 `series` 自动路径在精修后执行实际配音、独立内容与画面审核、局部修复，再冻结稿件渲染导出；不要求人工逐段核定。精修通过本身不等于完整内容验收。

`configs.production.toml`、`configs.long.toml`和示例剧配置启用`oral_edit=true`。基础Settings保留关闭值供已有集成兼容；采用项目提供的生产配置即可启用，无须Codex在旁补改。固定稿`render-sample`不会自动执行新精修，继续遵守已有审核绑定。

精修只能提出原有narration.text的改动；标题、角度、原声、镜头顺序、时间码和证据ID都不能改，每段按发音字符数控制在原段65%–120%（短段下限5字、上限至少12字），不计标点与空白。该范围只防止精修变成大幅重构，不代替实际配音时长验收。

最多两轮全稿提案，每轮另发一次改动核对。超出字数范围时，仅针对该段按 `repair_attempts` 有限重试，每次最多给出3种候选，由程序按实际发音字符数选择，不机械截断正文。第二轮只修审核指出的问题段，保留其他合格修改；合并后的全稿仍须独立核对。因此不再将总请求数限定为四次，所有请求仍受 `max_api_calls` 约束。可改口播明确给出镜头编号，避免长稿按段落重新数号误改原声。即使模型建议不改字，也检查完整新稿的听感，未改段不能漏审；旧新对照文本不合计成重复。核对分开记录新增事实错误、旧稿已有疑点、严重听感问题和可选措辞建议，细小连接词建议不阻止出稿。旧疑点不伪称是换词造成，也不能当作已解决，须交给后续完整内容审核。核对只读取观众会听到的文字，内部剪辑理由保存在记录中，不当作旁白主张。若两轮提案被拒绝，可另行独立审核未改原稿的听感；只有原稿无明确审查措辞、审核明确通过且没有新增事实/严重听感问题时，才保留原稿进入后续完整画面审核。原稿疑点仍保留；回查拒绝或服务故障则停止，不删除限定强行出片、不转用其他收费接口。

检测到明确审查措辞时会要求自然重写，不做字符串删除。精修与修稿共用写作规则；配音后再次检查实际使用的文字，避免时长修复把审核腔补回来。所有模型提案与核对记录保存在忽略的运行目录，不包含密钥。

## 本轮验证的边界

真实Go Flash测试发现，旧稿精修会只换词、继续附带无益猜心；程序已按两轮上限拒绝这类提案。定向短语检测归零，只说明显眼术语消失，不能当成精彩程度的证明。因此另检查全稿的来源、重复限定与听感，不依赖词频自动评分。第五集还采用开发逐段改稿；自动精修检查通过不能掩盖这部分人工参与。

测试同时覆盖原声/时间码/证据不变、错误修稿拒绝、有限重试、真实未知保留，以及短片与提纲写稿接入。下一条新片仍需用实际成片验证观点递进和听感，不能保证每次模型稿都精彩。

第五集抽查还发现：正确的总结配上下一场人物养伤画面，仍会让结尾松散。定稿检查应先确认首尾画面与论点的关系；若关键原声已经直接回答开头的问题，可以让原声收束，不强制再补一段旁白。不能拿无关后续镜头、重复播放或拉长定格填补结尾时长。本次由开发抽帧发现并修正，自动识别此类不相关尾声仍待验证。


## 自然口播复核（2026-10-24）

第十集重制稿虽然增加了解说分量，仍出现“拆掉怀才不遇的叙事”“把道义解释权收回皇帝手中”等抽象总结，以及对请安、落座硬加“掌握节奏”的解释。字数、解说占比和三项整稿核验没有覆盖这些表达问题。

现写稿、精修及修复共用自然讲述规则：说清谁用什么理由、对方如何回应、谁承担眼前后果；删去无信息增量的段尾总结，段落结构随情节变化。不以堆梗、编心理、替角色喊话或反问代替自然。正式长片的最终整稿新增 `naturalness`，与连贯性、分析、重复四项分别给出结论；任一未过必须定位真实原句，再局部修复、测时、核事实、整稿重审。局部修订核验同样读取自然口播要求，不接受只换抽象词的近义表达。旧三项核定不能跳过新检查。

这是一项表达核验，不给AI检测概率，也不代表模型能保证主观听感。第一集自然解说版正在通过实际生产验收；最后仍以成片试听评价。
